====================
系统（System）
====================

Python 提供强大的 modules 用于与操作系统交互，使其成为系统管理、自动化和脚本任务的绝佳选择。 ``os`` module 提供对文件系统、processes 和环境 variables 的便携式访问，而 ``datetime`` 则处理时间和日期操作。 ``pathlib`` module 为文件系统路径提供面向 object 的接口， ``subprocess`` 支持运行外部命令。本节介绍基本的系统操作，包括文件操作、目录遍历、process 管理以及跨不同平台处理日期和时间。
