快速入门（Quick Start）
==================================

本速查表旨在帮助开发人员从头开始学习 Python 语法。它涵盖了基础知识，同时还介绍了经验丰富的 Python 开发人员使用的常见模式和习惯用法，这对初学者来说可能会感到陌生。对于 instance，像 ``for ... else ...`` 这样的结构在其他编程语言中很少见到。此外，我们还将探讨一些有趣的主题，例如 ``__future__`` 、打字和 Unicode——您可能听说过但从未完全理解的概念。通过完成这份速查表，您将在 Python 中获得坚实的基础，并学会编写真正 Pythonic 的代码。
